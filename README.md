# Первокурсник в лицах — фоторепортаж

Статический сайт (HTML, CSS, JavaScript) без сервера и внешних сервисов. Работает локально и на GitHub Pages.

## Архивы «Скачать все» и контакты
- **Миниатюры, картинка для ссылок и архивы.** После добавления или замены обработанных фото выполните один раз `pip install pillow`, затем `python3 tools/make_thumbs.py`. Скрипт обновит превью в `assets/photos/thumbs/`, картинку `assets/photos/og.jpg` и архив обработанных фото `downloads/…-edited.zip`. Эти файлы коммитятся в репозиторий.
- **Архив исходников** слишком велик для репозитория (лимит GitHub 100 МБ на файл). Скрипт кладёт его в папку `release/` (она не попадает в репозиторий). Загрузите его на GitHub: страница репозитория → справа «Releases» → «Create a new release» → в поле «Choose a tag» впишите `originals` и нажмите «Create new tag» → перетащите файл из `release/` в область «Attach binaries» → «Publish release».
- **Контакты** вписываются в `siteConfig.contacts` в `photos.js` (ссылка на профиль). Пустые значки не показываются.
- Адрес сайта в `og:image` и `og:url` в `index.html` и ссылка на архив исходников в `photos.js` содержат имя репозитория, при его смене поправьте их.

## Структура
- `tools/check.py` — проверка наличия всех фотографий
- `index.html` — разметка страницы
- `assets/js/photos.js` — **вся конфигурация**: названия, даты, описание, список фотографий
- `assets/js/main.js` — логика галереи, просмотра и скачивания
- `assets/css/style.css` — оформление
- `assets/photos/edited/` — обработанные фотографии
- `assets/photos/original/` — оригиналы

## 1. Запуск локально
Откройте терминал в папке проекта и выполните `python3 -m http.server 8000`, затем откройте http://localhost:8000. Двойной клик по `index.html` не подойдёт: скачивание и проверка файлов требуют HTTP.

## 2–4. Добавление десяти фотографий
- Обработанные: `assets/photos/edited/01.jpg` … `10.jpg`
- Оригиналы: `assets/photos/original/01.arw` … `10.jpg`

Все кадры горизонтальные. Для обработанных лучше длинная сторона 2000–2400 px и размер до 1 МБ: сайт показывает их как есть, миниатюры не генерируются. Оригиналы сохраняйте без изменений. Если у файла другое расширение (например `.jpeg` или `.png`), впишите его в `photos.js`. Имя при скачивании получит то же расширение.

Перед публикацией выполните `python3 tools/check.py`: скрипт покажет, каких файлов из `photos.js` не хватает.

## 5–6. Названия, подписи, заголовок, описание
Откройте `assets/js/photos.js`. В `siteConfig` меняются `projectTitle`, `eventName`, `dateLabel`, `description` (список абзацев, каждая строка — отдельный абзац), `photographer`. В массиве `photos` меняются `title`, `caption`, `alt` у каждого кадра. Название проекта хранится только в `projectTitle`.

## 7. Одиннадцатая и следующие фотографии
Положите `11.jpg` в `edited/` и оригинал в `original/`, запустите `python3 tools/make_thumbs.py` и добавьте в массив `photos` ещё одну запись по образцу предыдущих (`id: "photo-11"`, `number: "11"`). Карточки создаются автоматически. Чтобы удалить кадр, удалите его запись.

## 8. Загрузка в GitHub
1. Создайте на github.com пустой публичный репозиторий, например `pervokursnik-v-litsah`.
2. В папке проекта выполните:
```
git init
git add .
git commit -m "Фоторепортаж"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/pervokursnik-v-litsah.git
git push -u origin main
```
Без Git: на странице репозитория нажмите Add file → Upload files и перетащите содержимое папки.

## 9–10. Включение GitHub Pages и ссылка
Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save. Через 1–3 минуты ссылка появится вверху страницы: `https://ВАШ_ЛОГИН.github.io/pervokursnik-v-litsah/`.

## 11. Проверка опубликованного сайта
Откройте ссылку на телефоне и компьютере. Проверьте, что видны все десять карточек, открывается выбранный кадр, работают стрелки, Escape и свайпы, а обе кнопки скачивания отдают нужные файлы. Если вместо фото видна заглушка, проверьте имя файла и регистр букв: на GitHub Pages `01.JPG` и `01.jpg` — разные файлы.

## 12. Обновление после замены фотографий
Замените файлы с тем же именем, затем выполните `git add . && git commit -m "Обновление" && git push`. Если страница показывает старое фото, обновите её с очисткой кеша (Ctrl+F5).

## Важно
Оригиналы здесь — RAW-файлы Sony (`.arw`, около 47 МБ каждый, всего около 470 МБ). Это в пределах лимитов GitHub (файл до 100 МБ, репозиторий желательно до 1 ГБ). Если загружаете через сайт, а не через Git, файлы такого размера лучше добавлять через `git push`.

Репозиторий публичный, поэтому оригиналы может скачать любой, у кого есть ссылка на файл. Скрытие кнопок их не защищает. На сайте нет аналитики и внешних запросов.
